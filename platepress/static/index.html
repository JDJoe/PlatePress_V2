Help

One book at a time. ComfyUI must already be running. This app does not download the checkpoint.

Loop

  1. Settings — pick a style card, Test connection.
  2. Cast — this book’s people. Optional stills.
  3. Book — paste the labeled shot wall. Parse. Generate.
  4. Queue — watch the plates. Captions and balloons are in the picture when you Generated with the letter column on. Plate size does not change.

Settings

  • Ink, layout line, closer, NEG, UNET, LoRAs are shared Settings (not stored on the book). Cast, story, plates, Text/Image per slug, and the book’s API workflow belong to the open book. Default graph: krea2_character_consistency_workflow-03-API.json. NEG is written only if that graph has a CLIP negative node; the shipped default keeps its diptych negative.
  • Test connection first.
  • Style cards are the mode. There is no Plate layout radio.
  • Bos, one plate: each slug is one image. If that slug contains left pane: / right pane:, only that plate splits.
  • Two-pane comic: consecutive slugs share one image (p1 left, p2 right). Do not write “Left pane” yourself. Each pane is its own scene as written.
  • Click a card to fill ink, layout line, and matching negatives, and save Settings. World closer stays empty on Bos; two-pane fills the pane closer. The boxes stay editable.
  • Ink and Layout line are prepended to every plate. World closer only if that box has text (empty on Bos).
  • On Book, each slug has Text, Image, and letter. All start off. Text inserts the Cast lock. Image sends the still. letter sends captions and balloons to Comfy on the plate (same size, no bar under the image). Header checkboxes select or clear a column.
  • Model and LoRAs — shared Settings. Load lists from Comfy and pick the exact UNETLoader name. Combo name is the listed folder plus the listed file (KREA2/krea2_turbo_bf16.safetensors). Softlinks keep those names. Must be a Krea 2 UNET. Not saved on the book.
  • API workflow is per book. Default is Settings krea2_character_consistency_workflow-03-API.json. Open the default in Comfy, change nodes or parameters, Save (API Format), put the JSON in this book’s workflows/ folder, pick it on the Book page. Extra nodes stay. The app still fills prompt, seed, Settings UNET/LoRAs, and the save prefix.
  • Do not touch sampler unless you mean it. Factory: 8 steps, CFG 1, euler, beta.

Cast

  • Cast is per book. Five books can all have ANDROID; they are not the same person.
  • Header plus Cast, Book, Queue, and Settings headings show the open book.
  • First card is CHARACTER1 / PILOT1, second is CHARACTER2. The name on the card is for you; Anna in the wall is writer text.
  • Lock is face + suit + pack. Per-slug Text on Book inserts it. Per-slug Image sends the still. Cutout is per character on this page and is sent when Image is on.
  • A name like PATRON only works if that card exists on this book.
  • 0–3 local stills per card. One body. Frontal portraits make the figure find the camera.
  • Lock seed on a thumb in Queue, then later plates of that character can reuse it.
  • Load demo cast replaces this book’s roster, not a global list.

  • Slug on its own line. Cast name can be anything. Wall CHARACTER1 / PILOT1 is the first card. Text: token becomes the lock, is PingPong stays. Image: still is image1. Both: lock in the prompt and the still. Write KEEP yourself.
  • Do not paste ink, closer, sampler, or aethernouveau here. The app prepends ink and the layout line (and closer if that box is not empty).
  • Hide the eyes. Working verb: caught in the instant of [verb].
  • Captions go to Comfy when the letter column is on. Untagged lines become a bottom box on the plate (CAP_B). CAP_T is the top box. Place a balloon: NS_6: line — grid 1 2 / 3 4 / 5 6. The plate size does not grow.
  • The default book is the demo. It cannot be deleted from the UI.
  • Parse before generate. Check the two-shot column. Click a prompt (or Copy) to copy the full assembled text Comfy will get.
  • Header checkboxes: generate-select, Text column, Image column.
  • Generate selected uses the checked rows and always queues a new version. It Parses first. Skip only applies to Generate missing.
  • Assembler: ink, layout line, closer (if any), Book wall. No KEEP line is added.
  • Two-pane comic: one checked row uses the next slug as the right pane. Write a full shot on each slug.
  • Default: 2 random seeds per plate.
  • Copy instructions for your LLM copies the sheet plus current locks (identity notes, not prompt prefix).

Metaphor examples: spiderweb of black cells; wet silk into teal glass; stained glass; gold leaf over black glass; liquid silver; fire-silk; enamel. Hang a metaphor on a named object.

Refs

Queue / Letter

  • This page shows only the open book. Click a thumb to view it larger (Esc or click the dark to close).
  • File names: {book_id}_v01_p001_slug.png; two-pane pair {book_id}_v01_p001_slug_p002_other.png; second seed …_2.png. Each Generate is a new version, newest grid on top. p010 after p001. No seed in the name.
  • Thumbs land in the book plates/ folder.
  • Letter all / Letter this is optional extra drawing on a copy. The usual path is Generate with the letter column on.
  • Export pack writes lettered PNGs, captions/, assembled_prompts.txt, seeds.json.
  • Reroll = new seed from the current Book wall (saves first), not the old file. New version.
  • Delete one file, earlier versions, or all plates in this book (story/stills stay).

House style

  • No text, logos, balloons, or “comic panel with text box” in the sampler.
  • No NASA, EMU, flags, patches — those pull a different suit.
  • One character per plate unless both bodies must appear.
  • Do not change identity words mid-book.
  • Vessels are spacecraft. The word ship (and spaceship) makes Krea paint boats with sails.
